# 知乎文章

每篇文章使用一个独立子文件夹，集中保存正文、图片和参考资料。

## 文章索引

- [为什么 Gather 有时很慢：从访存瓶颈到乱序 TMA](Gather性能研究/正文.md)：技术文章修饰稿，含概念插画与四张技术图。附[行文策划](Gather性能研究/提纲.md)与[调研笔记](Gather性能研究/参考资料/调研笔记.md)。

## 使用方法

1. 新建文章时，复制 `_模板/` 并将副本改为文章名称。
2. 在 `正文.md` 中撰写正文，将图片放入 `图片/`，资料放入 `参考资料/`。
3. 在本页文章索引中添加链接；文章文件夹更名时同步更新链接。
