## Layered authoring and review

- [ ] Establish the Beamer entry, theme, macros and section includes from the source plan; agree visual conventions before adding detailed frames.
- [ ] Outline each section, then choose assets and excerpts, then write frames and speaker notes. Preserve the running example across layers.
- [ ] Record repository, branch/release, commit or working-tree identity, source path and line for every excerpt. Confirm public disclosure scope before embedding local or SSM material.
- [ ] Use concise real snippets and outputs. Do not fabricate IR, emitted files, commands, results, approvals or PPA measurements. Keep explicit asset placeholders when needed.
- [ ] Keep terminology consistent: Normative Description Format; contract refinement versus hardware hierarchy; struct/module/Rule; independent oracle; C++ simulation; Verilog; evidence scope.
- [ ] Preserve the planned completed-flow narrative while keeping current-snapshot limits in authoring notes. Do not present those limits as a completed historical result.
- [ ] Later compile the LaTeX deck, resolve errors/missing assets and references, inspect warnings, render every page, and review clipping, contrast, code legibility, diagram labels and notes. Review all frames as a coherent narrative before delivery.

This checklist performs no snippet retrieval, model tests or deck compilation. Current [authoring background](pycircuit-section-brief.md) and local source entries remain preparation aids.
