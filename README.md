Each future activity gets a peer directory under `events/`, with independent slides, speaker notes, assets and sources. Add it to this index; keep shared tooling at root.

Root `assets`, `content`, `decks`, `docs`, `experiments`, `materials` and `public` are compatibility aliases to the summer-school archive. Existing session routes and npm commands remain available.

Use `npm ci`, `npm run dev:1` or `npm run dev:2` for the archived course. `npm run dev:efcl` opens the English placeholder. `npm run build` includes the activity index and static EFCL placeholder through the existing Pages build.
